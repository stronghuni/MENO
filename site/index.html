회의는 당신의 컴퓨터 안에서 끝납니다.

Whisper 전사와 Qwen 회의록 작성은 모두 로컬에서 실행됩니다. API 키나 계정이 필요 없고, 데이터는 사용자가 직접 누른 Notion·Jira 전송을 제외하면 외부로 나가지 않습니다.

WHAT MENO DOES

회의 하나에 필요한 전부.

01

마이크 녹음 · 기존 파일 업로드

회의를 바로 녹음하거나 mp3·wav·m4a·flac·mp4·mov·avi·mkv 파일을 놓으세요. 자동으로 16kHz 음성으로 바꿔 처리합니다.

02

로컬 한국어 STT

Whisper Large-v3 Turbo와 Metal GPU 가속으로 받아 적습니다. 긴 회의는 자동으로 나누고, 각 구간의 결과를 바로 보관합니다.

03

실시간으로 채워지는 회의록

Qwen 2.5-7B가 TL;DR, 안건, 논의, 결정, 액션 아이템을 표준 형식으로 씁니다. 무음이나 반복 음성에서 생기는 환각도 걸러냅니다.

04

회의 관계 그래프 · 캘린더

참석자와 주제가 겹치는 회의를 연결하고, 회의록에서 다음 일정을 찾아 캘린더와 시작 전 알림으로 이어줍니다.

05

Notion · Jira 연동

완성된 회의록을 Notion에 올리고 액션 아이템을 Jira 이슈로 내보냅니다. 연동 토큰은 운영체제의 안전한 저장소에 보관합니다.

THREE QUIET STEPS

받고, 모델 한 번 내려받고, 녹음.

  1. 01

    다운로드 & 설치

    내 컴퓨터에 맞는 설치 파일을 받고 MENO를 설치합니다.

  2. 02

    모델 자동 다운로드

    첫 실행 온보딩에서 Whisper와 Qwen 모델 약 6.3GB를 내려받습니다. 끊겨도 이어받습니다.

  3. 03

    녹음 또는 파일 놓기

    녹음을 끝내면 전사와 회의록 작성이 시작됩니다. 원하면 Notion 업로드까지 자동으로 이어집니다.

$ xattr -dr com.apple.quarantine /Applications/MENO.app

macOS 미공증 빌드는 처음 한 번만 위 명령으로 격리 속성을 풀어주세요.

FIRST RUN GUIDE

처음 한 번만, 차근차근.

macOS

받아서 바로 쓰기

  1. 맥 종류에 맞는 DMG를 받고 MENO를 Applications 폴더로 옮깁니다.
  2. 미공증 빌드라 처음 실행할 때 막히면 아래 명령을 한 번 실행합니다.
$ xattr -dr com.apple.quarantine /Applications/MENO.app
  1. 첫 녹음에서 마이크 접근을 허용합니다.
  2. 온보딩이 Whisper 1.6GB와 Qwen 4.7GB를 내려받으면 준비가 끝납니다.

이 명령은 다운로드 파일의 격리 표시만 지우며 앱 자체를 수정하지 않습니다.

Windows

설치 파일로 시작하기

  1. 설치 파일을 실행합니다.
  2. SmartScreen이 열리면 추가 정보 → 실행을 선택합니다.
  3. 마이크 권한과 모델 다운로드를 마치면 바로 사용할 수 있습니다.
DEVELOPER

소스에서 빌드

$ git clone https://github.com/stronghuni/MENO.git && cd MENO
$ npm install
$ npm run dev

Node 20.x / 22.x LTS와 Xcode Command Line Tools를 권장합니다.
